01 / Today

Support is a link, a guess, and a lot of tabs.

Players
No real help in the stores
Prime Rush's SUPPORT link goes to Discord. MaskGun has an FAQ and an email. Tower Conquest's chat doesn't know who you are.
Live problem
Wrong game, wrong answers
Tower Conquest's chat calls our bot anonymously, and gets Prime Rush answers.
Sign-in
Three separate logins
Prime Rush stores, Tower Conquest and MaskGun each sign players in their own way. Nothing is shared.
Operators
Work in five places
Discord, email, Freshdesk, store reviews, the ops dashboard, plus each store's admin.
What players want
Nobody sees the pattern
When a delivery system breaks, we hear about it from angry reviews hours later.
When it's fixed
We never come back
Players have to check again themselves. No push, no mail, no "it's done".

05 / How it talks

Fast, short, does things, comes back.

Modelled on Instinct, the personal agent we use on WhatsApp.
Instant
👀 then "Got it —"
Reacts in a second, acknowledges in two, then answers.
Answer first
"Done — it's in."
Short bubbles, one to three per turn. No walls of text.
Proactive
Opens with what it knows
A failed delivery, a failed payment, an expiring reward, an outage.
Acts
Does, doesn't ask
Re-send, equip, claim, link. Refunds and currency go to a person.
"Viper. Your Gold Vest drop never made it out of the armoury 20 minutes ago. Already sent it again."
— Mysterio, MaskGun

08 / SuperX ID

One sign-in for all our games.

From the game: a one-time code signs the player in. Nothing to type.
On the web: game ID + a code sent to in-game mail, or Google, or Apple.
Sign in once on any superx.gg site and you're in on all of them. Prime Rush stores on other domains use a quick redirect.
Built on the Prime Rush account system we already run.

12 / Reports

Know what players want, every day.

Every message is tagged with what the player wanted. An LLM writes a daily digest per game.
A spike alert when one ask jumps 3× in an hour, usually a broken backend.
OpenPing runs a test conversation per game every 15 minutes.

13 / How it fits together

Built on what we already run.

Game clients
Prime Rush, Tower Conquest, MaskGun. Open the store with a one-time code.
Stores (Vercel)
primerush, towerconquest, maskgun .superx.gg and the Prime Rush stores.

SuperX ID on the Prime Rush account system.

Player site + the concierge in every store.
Support engine
Our chat agent, KB, tickets, takeover. Becomes multi-game; chats move to Postgres.
ops.superx.gg
Today's ops dashboard, on SuperX.
GameGateway v2
The stores' game calls (profile, orders, re-deliver, mail, coupons) in one shared service.
OpenPing
Watches the site, the engine and a test chat per game.
OpenPush + in-game mail
Tell the player when it's fixed.
